期間：18期 = 2025/10〜2026/9 の12ヶ月（モデル内 m0〜m11）。

  • 実績がある期間 = 2025/10〜2026/5（m0〜m7、8ヶ月）。取締役CSV・17-18期再集計CSVともこの8ヶ月まで実数。
  • 2026/6〜2026/9（m8〜m11、4ヶ月）は未着地。各CSVに実数が無いため「予測」（§3の方法で算出）。

使った資料（フォルダ直下）：

  • 資料A＝取締役使用数値_18期 - 全国.csv（売上額・月初積上・売上単価・応募数・応募単価・広告費・継続率・新規稼働率）
  • 資料B＝17-18期_応募〜稼働再集計 - 集計.csv（新規稼働＝確定締めの実数）
  • 資料C＝HTML埋込PL（UNITS sc.d）＝18期修正予算CSV シニアケアD合計と全項目一致を確認済み（売上・原価・販管費の各科目の月次決算値）

2. 原価・人件費・販管費の全項目トレース

売上ドライバー以外の原価・人件費・販管費は、すべて資料C（PL＝18期修正予算CSVと一致）の月次決算値をそのまま使用。新規推計はほぼ無く、PL科目をモデル行に割り当てている。

用語「seed」：HTMLコード内 KCFG.sc.seed ＝18期の基準値を置いた設定ブロック。当初は計算で出せる値（平均給与・原価単価）まで固定値でベタ書きしていたが、「計算できる値は計算行に（連動）」「外部値は直接入力に」分離済。

3. 予測月（2026/6〜2026/9）の算出方法と理由

未着地の4ヶ月。資料に実数が無いので以下で予測：

  • 月初積上 active＝資料C PLの6-9月売上(着地見込)から逆算 = (PL純売上 − 紹介売上) ÷ 売上単価平均。結果：m8=2,865 / m9=3,000 / m10=3,027 / m11=2,898 名
  • 売上単価＝実績8ヶ月平均305,556円／紹介売上＝平均18,629,420円／派遣売上＝PL純売上 − 紹介(→売上PL一致)
  • 広告費・応募単価・新規稼働・継続率＝実績平均
  • 理由：6-9月は売上の着地見込(PL)が最も信頼できるので、それに売上が一致するよう積上を逆算。係数は直近実績の平均(季節性なしの簡便法)。

4. 検証で確認済みの整合（すべて成立）

  • 応募人数 = 広告費 ÷ 応募単価 → 資料Aの応募数と一致(誤差0)
  • 派遣売上 = 月初積上 × 売上単価 → 資料Aの売上額と一致
  • 売上 = 派遣売上 + 紹介売上 → 資料C PL純売上と完全一致(全12ヶ月、年計0円差)
  • 売上原価・販管費・営業利益 → 資料C PLと完全一致(年計0円差、営利のみfloat1円)
  • ロールフォワード恒等式：月初積上 = 前月積上 − 終了数(月) − 終了数(不明) + 新規稼働 → 恒等成立

5. 判断が入っている箇所（要注意）

  • 新規稼働を資料B(467…)にした：資料A(258…)は翌月15日締めで過小という判断。
  • 「不明」列：継続率で説明できない純増減(m0-7で−142〜+147名)。拠点移管・中途異動・カウント月ズレ・期末退職集中・丸めの累積、という解釈。19期以降は18期平均の不明を継続適用(退職等の純減を計画年も見込む)。
  • 継続率5月(空)→平均で補完、3月80.60%はそのまま。
  • 予測月の係数を直近平均で置いた(季節性なし)。6-9月の売上はPL逆算でPL一致するが、係数は平均値。

7. PLタブとの連動（19-21期）

  • 18期(実績)＝決算確定値で固定（PLタブもKPIモデルも変更不可。資料Cの月次決算そのまま）。
  • 19-21期(計画)＝KPIモデル(このタブ)で計算した値がPLタブにも反映。KPIモデルで広告費・人員・成長率等を変えると、PLタブの19-21期売上・原価・販管費・営業利益が連動して動く。
  • scの19期以降：広告費 → 応募人数 → 新規稼働(=応募×新規稼働率) → 稼働数 → 売上 が連鎖（広告を増やすと売上が増える）。新規稼働率は入力レバー。
  • PLタブの19-21期の販管費・原価の科目内訳：KPIモデルは集計値(売上/原価/販管費計/営利)のみ計算するため、内訳科目は「18期の構成比 × 計画年の親集計」で按分表示。原価側は「原価不明(その他原価等)」残差行で内訳合計＝売上原価を完全一致させている（4科目だけでは届かない分を吸収）。販管費側も内訳合計＝販管費計で整合。科目別の独立した計画ではなく親集計の按分である点に注意。
  • ※driverモデル(sc)は19期で月初積上を平準化するため、成長率0でも18期と完全一致はしない(年営利763→783百万、約2.6%差)。月次実績のデコボコがロールフォワードで均されるため。
